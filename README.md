# solor-zipu（星隼号 ZF-77 飞船版 3D 太阳系）

> 基于 React + Three.js 的 3D 太阳系，新增一艘可自由飞行 / 自动驾驶的星球大战风格星舰「星隼号 ZF-77」。

## 项目简介

solor-zipu 是在 3D 太阳系网页基础上，新增一艘原创星际飞船 **星隼号 ZF-77** 的版本。飞船支持 **自动驾驶导航到任意天体**（随行星转动持续追踪最佳观赏点）、**自由驾驶**，以及 **舱内第一视角**（巨型透明舷窗 + 可收起全息控制台）与 **舱外第三视角** 一键切换。

本仓库为独立新仓库，由 [chenbenkong/sy-826](https://github.com/chenbenkong/sy-826) 衍生而来，原仓库保持零改动。

## 功能特性

### 太阳系模式（原有功能）

- 鼠标拖拽旋转视角，滚轮缩放，点击星球查看信息并聚焦
- 右上「导航」面板：选择天体直接跳转（飞船模式下同样可用，会触发飞船自动驾驶）
- 底部控制栏：暂停 / 时间流速 / 轨道线 / 星空 / 名称 / Bloom / 光晕 / 全局缩放 / 黑洞体验
- 快捷键：`Space` 暂停、`↑/↓` 调时间流速、`Esc` 退出

### 飞船模式（星隼号 ZF-77）

点击「登上飞船」进入，提供三种飞行模式：

1. **景观悬停**（默认）—— 飞船悬浮原地，相机缓慢环绕，可完整欣赏飞船本体。
2. **自由驾驶**

   | 按键 | 功能 |
   |------|------|
   | `W` / `S` | 加速 / 减速倒退 |
   | `A` / `D` 或 `←/→` | 偏航转向 |
   | `↑` / `↓` | 俯仰（抬头 / 低头） |
   | `Q` / `E` | 滚转 |
   | `Shift` | 加力推进 |
   | `V` | 切换舱内 / 舱外视角 |
   | `C` | 收起 / 展开控制台 |
   | `Esc` | 退出飞船模式（相机恢复原位） |

3. **自动驾驶**
   - 打开底部控制台 →「自动导航」→ 选择任意星球 / 太阳 / 卫星 / 小行星
   - 飞船自动脉冲跳跃 → 接近减速 → 锁定 **最佳观赏点**（背阳侧偏外、阳光照亮面）
   - 锁定后随行星 **自转与公转持续追踪**（锚点前馈零滞后），始终保持在向阳面最佳观赏角度
   - 最佳观赏参数自动保存（localStorage），下次导航同一目标直接复用，跨页面刷新依然生效
   - 导航中可随时点「解除自动驾驶」或切换自由驾驶手动接管

### 双视角

- **舱内第一视角**：视点位于气泡舷窗内，透过巨型透明舷窗观赏太空；底部全息控制台可点击收起/展开（快捷键 `C`），外观部件自动隐藏保证视野无遮挡
- **舱外第三视角**：后上方追踪镜头，完整呈现飞船与周围天体
- `V` 键或控制台按钮一键切换

## 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| React | 18.2 | UI 组件与状态管理 |
| react-dom | 18.2 | 渲染 |
| Three.js | 0.160 | 3D 渲染引擎 |
| Vite | 5.0 | 构建工具（`@vitejs/plugin-react`） |

- 飞船为 **程序化 3D 建模**（`src/three/ship/createStarship.js`），无外部模型文件，原创设计致敬星球大战风格
- 行星贴图位于 `public/textures/`，全部本地资源，无外部 API 依赖

## 目录结构（新增部分）

```
src/
├── three/ship/
│   ├── createStarship.js   # 飞船程序化建模（机身/四翼/引擎/座舱/内饰）
│   └── ShipSystem.js       # 飞行状态机、自动驾驶、观赏锁定、双视角相机
├── components/
│   └── CockpitHud.jsx      # 驾驶舱 HUD（舷窗相框/控制台/导航列表/状态条）
└── styles/
    └── cockpit.css         # FUI 驾驶舱样式（琥珀/青全息风格）
```

修改指引：

- **调整飞船外观/涂装**：`src/three/ship/createStarship.js` 顶部颜色常量
- **调整飞行手感**（速度/转向/观赏距离）：`src/three/ship/ShipSystem.js` 构造函数参数区
- **调整观赏点逻辑**：`ShipSystem.js` 中 `_computeViewPosition()`（`viewFactor` 控制距离）
- **新增导航目标**：`src/data/planetData.js` 或 `SolarSystemScene.createNamedAsteroids()`
- **HUD 文案与布局**：`src/components/CockpitHud.jsx` + `src/styles/cockpit.css`

## 本地运行

```bash
npm install     # 安装依赖（React 18 + Three.js + Vite 5）
npm run dev     # 启动开发服务器，自动打开 http://localhost:3000
npm run build   # 生产构建，输出到 dist/
npm run preview # 本地预览生产构建
```

打开开发服务器后，点击底部控制栏的 **「星隼号」** 按钮即可进入飞船模式。

## 说明 / 备注

- **部署结构**：分支 `main` 为源码，GitHub Pages 从 `main` 根目录部署；`vite.config.js` 中 `base: './'`（相对路径），同时兼容 Pages 子路径与本地预览。
- **异常兜底**：
  - WebGL 不可用 / 渲染异常：页面显示友好错误浮层，不白屏（React 错误边界 + 全局错误捕获）
  - 后期管线（Bloom 等）初始化失败：自动退回普通渲染
  - 贴图加载失败：6 秒后强制关闭加载页，场景仍可进入
  - 导航目标不存在：HUD 提示「导航目标未找到」，飞行状态不受影响
  - 观赏锁定数据异常：自动重新计算最佳观赏点
  - 相机 / 飞船防穿模：太阳与行星碰撞守卫，不会进入天体内部
- **版本与回滚**：`git tag -l` 查看标签；当前版本 **v1.0.1**（v1.0.0 初始发布，v1.0.1 自动驾驶收敛与追踪优化）。

### 飞船细节检视系统（v3 新增）

飞船模式下点击「⬡ 细节检视」进入，三种子模式：

- **组合 360°**：飞船悬停于全息展示平台上方，自动环绕 + 拖拽轨道 + 滚轮缩放
- **爆炸拆解**：300 个部件按结构方向平滑炸开，拆解度滑块 0~100% 无级调节
- **舱内漫游**：第一视角进入座舱，拖拽环视 + W/A/S/D 移动，舱内照明自动开启

通用交互：悬停任意部件高亮 + 中文命名标签 + 引导线；`X` 或按钮退出检视。

### 星舰机库与多舰系统（v4 新增）

- **独立机库空间**：点击「细节检视」先进入星舰机库——专属渲染器的简约超空间，全息展台 + 顶部光柱 + 星云氛围，与黑洞体验同级独立界面
- **四款可选座舰**：星隼号（多域战斗机）、箭翎号（长距截击机）、霜环号（碟形巡航舰）、夜刃号（掠翼突袭舰），键盘 ←/→ 切换、Enter 出击
- **出击联动**：选定机型后主场景飞船热切换（swapShip 释放旧模型显存），结构检视面板标题/部件数随机型动态更新
- **爆炸图重调**：部件间距加大分层，疏朗通透；新增冷暖双补光灯（仅检视时开启）
- **工程优化**：three/react 代码分割（主包 1.2MB → 214KB）、站点 favicon 与 OG 元信息、检视系统部件去重与生命周期修复

### 星舰机库 · 白色科幻展厅（v5 重构）

## v6 天文星历与性能重构

- **真实轨道运动**：引入 NASA/JPL 风格 J2000 轨道根数与开普勒方程，支持椭圆轨道、偏心率、轨道倾角、升交点与真实公转周期。
- **模拟星历**：新增实时模拟日期、时间流速预设与「返回今日」；暂停后恢复不再出现位置跳变。
- **轨道可视化升级**：内行星与太阳保持安全距离，轨道线改由同一轨道算法生成；选中天体会高亮其真实椭圆轨道。
- **镜头一致性重构**：聚焦动画统一进入主渲染循环，自动追踪时按天体当前位置动态修正，不再产生多动画循环争抢相机。
- **性能优化**：关闭高成本的点光源立方体阴影、移动端降低天体与太阳网格细分、后台标签页暂停渲染，并继续保留自适应分辨率。
- **贴图资源压缩**：全部行星与银河贴图重采样至适合 Web 显示的尺寸并重新编码，纹理总体积由约 8.1 MB 降至约 1.4 MB（约减少 83%），显著改善 GitHub Pages 冷启动速度。

## v7 首屏加载重构与遮挡清理

- **加载链路重做**：全部运行时贴图转为 WebP，首屏实际请求贴图约 **0.44 MB（含海报约 0.53 MB）**；导航与天体档案改用 112px 独立缩略图。
- **渐进式首屏**：场景结构就绪即撤掉加载页，无界面场景海报接管等待期，完整 3D 纹理就绪后交叉淡入，避免一直盯着加载页。
- **重型模块按需加载**：星舰系统、星舰机库、黑洞、后期处理和外围小行星带均拆分为独立 chunk，首屏业务包由约 201 KB 降至约 112 KB。
- **启动主线程减压**：移除运行时逐像素生成法线图的流程；卫星程序化纹理降至 128px，小行星与柯伊伯带改用低分辨率程序化纹理并降低实例数量。
- **文字遮挡修复**：移除悬浮在场景上的“快速跃迁 / CELESTIAL INDEX”标题；天体标签按行星实际屏幕半径外扩，并自动避让太阳、其他天体、左侧文案区、右侧导航及底部控制栏；移动端隐藏行星标签。
- **移动端布局修复**：标题区下移避开“天体索引”按钮，索引栏与控制栏增加安全间距；390×844 视口无横向溢出。
- **观测站视觉精修**：强化首屏构图、天体索引纹理、星历状态与时间设置面板；新增 O / L / R 快捷键。

- **卫星可见性修复**：给卫星增加“远景最小可视尺寸”（按屏幕投影换算，近景回落为真实比例），并对齐初始轨道相位避免重叠，同时叠加随距离淡出的微弱光晕；月球、木卫一至四、土卫六与土卫二在全景下都能被看见与点选。

## v9 流畅度与时间节奏校准

- **后期通道合并**：把「色差 / 体积光 / 镜头光晕 / 色阶 / 暗角颗粒」5 个全屏 Pass 合并为 1 个合成 Pass，体积光采样从 64 次降到 12 次；加上 Bloom 后全屏后处理从 6 个降到 2 个，观感几乎不变。
- **像素预算与显卡分档**：按屏幕总像素量动态限制渲染分辨率（独显约 300 万、核显约 200 万、移动端约 120 万像素），4K / 2K 屏幕不再按 1.45 倍像素比满额渲染；同时关闭对后期管线无效的 MSAA。
- **自动降载修正**：此前调整渲染分辨率只作用于场景，后期管线没有跟着改尺寸，等于降载无效；现在 `applyPixelRatio()` 同步 EffectComposer，阈值从 27fps 提高到 45–50fps，分辨率到下限仍掉帧则自动关闭辉光。
- **光照精简**：移除 7 颗卫星各自的点光源（会拉长所有受光材质的逐像素光照循环），改由自发光与全局光照承担；星场点数下调约 35%。
- **时间节奏**：1× 由「每秒 1 个地球日」改为「每秒 2 小时」，行星缓慢移动、地球 12 秒自转一圈；需要快速看变化时用 10×（约每秒 20 小时）。设置面板文案同步更新。
- **卫星比例**：卫星尺寸改为以母行星视半径为基准（最大不超过行星半径的 12%、6px 封顶），缩小时与行星一同变小，不会再出现卫星比行星还显眼的情况。
